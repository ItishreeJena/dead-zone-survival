# ☣️ DEAD ZONE: SURVIVAL

> **The world fell silent. The dead did not.**  
> Explore a post-apocalyptic world, scavenge for supplies, survive zombie encounters, and make it through the night.

**DEAD ZONE: SURVIVAL** is a browser-based, first-person 3D zombie survival game built around open-world exploration, survival mechanics, atmospheric environments, and immersive audio.

---

## 🎮 About the Game

The world has collapsed, and every trip beyond safety comes with a risk. Explore abandoned locations, watch your supplies, listen for threats, and decide when to fight or flee.

### ✨ Features

- **First-person exploration** — move through a 3D post-apocalyptic environment.
- **Zombie encounters** — face zombies that can detect and pursue the player.
- **Weapons and combat** — use firearms and manage ammunition, where implemented.
- **Survival systems** — monitor health, stamina, hunger, and thirst.
- **Day-and-night cycle** — experience changing light and atmosphere as time passes.
- **Flashlight** — navigate darker areas when visibility drops.
- **Spatial zombie audio** — hear zombie moans and shuffling that become more noticeable as threats approach.
- **Scavenging** — search for useful supplies such as food, water, medicine, and ammunition.
- **Atmospheric world** — explore abandoned structures, damaged vehicles, roads, and natural surroundings.
- **Pause and restart** — manage your session and try again after a failed run.

> Some features may still be in development. Update this list as each feature is implemented and tested in the playable build.

## 🌅 Survival Experience

### Explore
Travel through abandoned streets and buildings, look for useful resources, and stay alert.

### Listen
Use positional audio to judge where zombie sounds are coming from. A nearby moan or shuffle could warn you before a zombie enters view.

### Prepare
Keep track of your health and supplies. Ammunition is valuable, and gunfire may draw unwanted attention if that mechanic is enabled.

### Survive the Night
As the environment grows darker, use your flashlight carefully and stay aware of the sounds around you.

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/dead-zone-survival.git
   ```

2. Enter the project folder:

   ```bash
   cd dead-zone-survival
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed in your terminal.

> **Note:** These commands assume the project contains a `package.json` with an `npm run dev` script. If your Google AI Studio export uses different scripts or setup instructions, follow the project's actual configuration.
